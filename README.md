# Лисий дневник

Локальный дневник с календарём, текстовыми и голосовыми записями, делами по датам и стикерами. Во вкладке «Лисья рукопись» можно вести планы и фактический объём текста для нескольких книг.

## Запуск на Windows

Нужен Node.js 22.13 или новее. Дважды щёлкните **`Запустить дневник.cmd`**. При первом запуске установятся зависимости и подготовится локальная база. Затем откроется [http://localhost:5173/](http://localhost:5173/). Оставляйте окно запуска открытым во время работы.

Подробные шаги и ручной способ запуска: [ЛОКАЛЬНЫЙ_ЗАПУСК.md](ЛОКАЛЬНЫЙ_ЗАПУСК.md).

## Данные и распознавание речи

Записи и файлы хранятся только в папке проекта, в `.wrangler/state`. Эта папка исключена из Git. Скопируйте её для резервной копии перед удалением или переносом проекта. Вход в аккаунт для локального запуска не нужен.

Голос распознаёт многоязычная **Whisper small** в браузере на вашем устройстве. Модель скачивается с Hugging Face при первом использовании и кешируется браузером; поэтому первое распознавание требует интернета и может занять несколько минут. Аудиозаписи сохраняются локально.

## Разработка

```powershell
corepack pnpm install --frozen-lockfile
corepack pnpm build
corepack pnpm dev
```

Сборка генерирует файлы браузерного движка распознавания в `public/runtime` и `dist`. Эти файлы не хранятся в Git. Локальные таблицы базы подготавливает Windows запускатор; ручные команды приведены в [инструкции](ЛОКАЛЬНЫЙ_ЗАПУСК.md).
