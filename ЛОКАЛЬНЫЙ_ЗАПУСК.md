# Лисий дневник — локальная версия для Windows

Это исходный проект. Для запуска понадобится Node.js 22.13 или новее и интернет при первой установке зависимостей и модели Whisper. Приложение будет открываться в браузере на вашем компьютере; база D1 и файлы R2 в этом режиме эмулируются локально.

## Первый запуск

На Windows можно просто дважды щёлкнуть **`Запустить дневник.cmd`** в папке проекта. Запускатор сам установит зависимости, подготовит базу, запустит сервер и откроет дневник в браузере. Для следующих запусков используйте тот же файл. Оставляйте окно открытым во время работы; для остановки нажмите Ctrl+C. При первом запуске потребуется интернет и Node.js 22.13+.

Ручной способ:

1. Распакуйте архив в постоянную папку, например `C:\Projects\fox-diary-local`. Не запускайте проект прямо из ZIP.
2. Откройте PowerShell в папке с файлом `package.json`. Установите Node.js 22.13+ с официального сайта, если его ещё нет.
3. Выполните команды по порядку:

```powershell
corepack enable
corepack pnpm install --frozen-lockfile
corepack pnpm build
corepack pnpm exec wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_thankful_spitfire.sql
corepack pnpm exec wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_next_storm.sql
corepack pnpm dev
```

Если команда `corepack` не найдена, установите её с помощью `npm install -g corepack`, затем повторите шаг 3. Если `corepack enable` сообщает об отказе в доступе, откройте PowerShell от имени администратора только для этой команды, затем вернитесь к обычному окну.

4. Откройте `http://localhost:5173/`. Дневник откроется сразу, без входа в аккаунт.

## Следующие запуски

В той же папке выполните `corepack pnpm dev` и откройте `http://localhost:5173/`. Для остановки сервера нажмите Ctrl+C в PowerShell. Не повторяйте команду создания таблиц: они уже есть.

## Где лежат данные

Локальные текстовые записи, дела, аудио и стикеры хранятся в `.wrangler/state` внутри этой папки. Сохраните резервную копию папки целиком, особенно `.wrangler/state`, прежде чем переустанавливать Windows или удалять проект. Не очищайте `.wrangler/state`, если хотите оставить записи. В архиве ваши существующие записи отсутствуют; данные опубликованного сайта автоматически сюда не переносятся.

Во вкладке **«Лисья рукопись»** можно добавить несколько книг. У каждой отдельно сохраняются месячный план, количество рабочих дней и фактически написанные знаки за выбранные даты. Число справа — ориентир `план на месяц / рабочие дни`; отметки в календаре его не пересчитывают. Если ввести `0` или поставить галочку «Это был рабочий день», на дате появится книжечка. Эти данные тоже хранятся в `.wrangler/state`. Запускатор при каждом старте проверяет нужные таблицы и сохраняет уже внесённые записи.

Локальная расшифровка использует многоязычную модель Whisper small и файлы движка из `public/runtime`. Модель скачивается при первом распознавании и обычно остаётся в кеше браузера. Скачивание и распознавание могут занять больше времени, чем с прежней Whisper tiny. После успешной загрузки small приложение удаляет из кеша только файлы прежней tiny. Без интернета первая расшифровка не запустится.

Если нужна синхронизация с опубликованным сайтом или перенос уже сохранённых там записей, понадобится отдельный экспорт и импорт. Текущий локальный запуск создаёт пустую базу.
